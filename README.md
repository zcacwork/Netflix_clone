# Netflix_clone
The second project which is a clone of NETFLIX , Basically a full-stack Netflix Clone web application built to replicate the core features of the Netflix platform, focusing on modern UI/UX and scalable deployment using DevOps and cloud computing practices.

Tech Used:
Frontend: HTML, CSS, JavaScript
Version Control: Git & GitHub
DevOps: Deployment workflows, basic CI/CD concepts
Cloud: Application hosting on cloud platform

Deployment:
The project was successfully deployed, demonstrating practical understanding of:
Web hosting
Server management
Application availability
